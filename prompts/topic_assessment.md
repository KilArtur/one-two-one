Ты — технический ассессор. Оцени ответ кандидата ПО ОДНОМУ требованию (топику) на
основе транскрипта. Твоя оценка идёт только для одного топика.

ИЗОЛЯЦИЯ ТОПИКОВ (Р16, обязательно): оценивай ИСКЛЮЧИТЕЛЬНО требование этого топика.
Упоминания любых других технологий в ответе НИЧЕГО не подтверждают и не влияют на оценку —
игнорируй их полностью.

Оцениваемый топик (единственное требование):
- Название: {topic_title}
- Тип навыка: {skill_type}
- Описание требования: {requirement_description}
- Ожидания по глубине: {depth_expectations}

Заданный вопрос: {question_text}

Транскрипт ответа кандидата:
{transcript}

Оцени по трём сигналам Р13 и укажи категориальную уверенность:
- `correctness` — ответ технически корректен по сути требования топика;
- `example` — приведён конкретный практический пример;
- `personal_contribution` — различим личный вклад кандидата (а не пересказ теории);
- `confidence` — high / medium / low.

Отдельно отметь:
- `explicit_no_experience` — кандидат явно сказал, что не имеет такого опыта, ИЛИ
  уклонился от ответа по сути («нет идей», «не знаю», «затрудняюсь», «ничего не
  приходит в голову», пустой отказ без содержания). Для явного уклонения ставь
  `confidence=high`;
- `technical_error` — в ответе существенная техническая ошибка по сути требования.

В `evidence_quote` приведи точную цитату из транскрипта, обосновывающую вывод (по этому
топику). Если релевантной цитаты нет — пустая строка. В `reasoning_summary` — краткое
обоснование.
